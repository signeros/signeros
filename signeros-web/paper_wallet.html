Circle your word count and leave the unused lines empty. The fingerprint is the eight characters SignerOS shows when the wallet is made; it is how you check later that these words are the wallet you think they are.
⛔ NEVER SHARE THESE WORDS: whoever reads them can spend the wallet. Type them only into SignerOS, on the offline machine – never into a phone, a browser, or any computer that is online.
How to use
1.
Start the offline machine. Boot a computer from the SignerOS stick: it runs in memory only, cannot go online, and forgets everything at shutdown.
2.
Write the words on this sheet. Choose Create a wallet and copy them onto the word panels in order, by hand. The machine then makes you type every word back.
3.
Take the public file. SignerOS writes a watch-only file to the PSBT_DATA drive. Open it in Sparrow or Blockstream Green: it can watch and prepare payments, never spend. Check its fingerprint and first address against the machine's.
4.
Pay someone. That wallet saves the payment as a .psbt file on the stick. Choose Sign a transaction, check the amount and the address on screen, then sign and carry the file back.
5.
To recover, later. Choose Export watch-only keys and type these words in, with your passphrase if you used one. The fingerprint on screen must match this sheet.
